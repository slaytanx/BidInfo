# 입찰 시스템 업그레이드 검증 기록

최신 업데이트: 2026-10-13

사용자의 후속 초기화 요청으로 이 기록의 기존 공고·첨부·수집 관련 검증 JSON·캐시·백업을 삭제했습니다. 합성 모델 비교 결과는 남겼습니다. 아래 수치는 초기화 전 검증한 과거 결과입니다. 현재 분류와 수동 검토 기능은 별도 분류 설계·검증 기록을 참고하세요.

## 완료한 변경

분야 사전 필터, 공개 수집원별 페이징, 다운로드 전 중복 검사, 제한된 병렬 처리, HWP 레코드 파서, PDF 페이지별 OCR, 캐시와 JSON 분석, 실행 비용 예약, 분야별 페이지, 로컬 비밀 설정과 선택적 R2 동기화를 적용했습니다. 루트 프로젝트만 변경했으며 `axolotl/`은 보존했습니다.

기존 DB는 `data/backups/`에 백업했습니다. 마이그레이션과 재추출·로컬 분류 이후 공고 69개와 기존 요약·찜·진행 상태의 일치를 확인했습니다. 69개 모두 태그를 기록했으며 자료가 부족한 경우 기타 또는 원본 확인 상태로 표시합니다.

## 문서 검증

| 형식 | 파일 수 | 성공 | 부분 성공 |
|---|---:|---:|---:|
| HWP | 79 | 79 | 0 |
| PDF | 38 | 36 | 2 |
| DOCX | 7 | 7 | 0 |
| HWPX | 1 | 1 | 0 |
| XLSX | 2 | 2 | 0 |

기존 HWP 파서는 40개에서 `index out of range` 오류를 냈습니다. 새 파서는 79개 전체를 추출했으며 최초 추출은 약 0.207초, 캐시 재사용은 약 0.022초였습니다. 79개 모두 파일 내 PrvText 미리보기의 한글 단어와 새 추출 본문 사이의 일치를 확인했습니다. 이것은 표 배치·모든 수치·읽기 순서의 완전한 검증을 의미하지 않습니다.

PDF 2개는 OCR 이후에도 텍스트가 부족한 페이지를 부분 성공으로 표시했습니다. 실제 공고별 폴더 재처리에서는 26개가 추출 성공, 43개가 읽을 첨부문서 없음으로 확인됐습니다. 다른 공고의 폴더를 대신 읽지 않았으며 기존 요약은 보존했습니다. 이 결과는 파일별 성공 수와 집계 기준이 다릅니다.

## 모델 비교

현재 분석 프롬프트로 합성 한글 RFP 12건씩 로컬 모델을 비교했습니다. 정확도는 마감일·제출방식·필수서류·참가자격을 모두 맞힌 문서의 비율입니다. 전체 5개 조건을 동시에 충족해야 성공으로 계산했습니다.

| 모델 | 중앙 처리 시간 | 필수 요건 완전 일치 | JSON 성공 |
|---|---:|---:|---:|
| gemma4:26b-mlx | 7.00초 | 100% | 100% |
| gemma4:12b-mlx | 12.84초 | 58.3% | 100% |
| qwen3.8:fast | 21.52초 | 25.0% | 100% |
| gemma4:e4b-mlx | 3.54초 | 8.3% | 100% |

따라서 상세 분석 기본값은 26B로 유지하고 E4B는 분류용으로 사용합니다. 모든 가격은 로컬 API 요금 0달러 기준이며 전력·장비 비용은 포함하지 않습니다. 합성 문서 평가이며 실제 RFP 정확도와 구분합니다. 캐시가 있는 재실행은 최초 추론과 비교하면 안 됩니다.

실제 저장된 HWP 한 건도 로컬 26B로 분석해 성공 상태와 원문 인용을 확인했습니다. 이 문서의 처리 시간은 약 28초였으며, 합성 평가의 중앙 시간과는 문서 내용·출력량이 다릅니다.

OpenRouter의 DeepSeek·GLM·Solar 연결과 선택 UI, 가격 상한·재시도·예산 부족 시 로컬 전환은 구현했습니다. API 키가 없어 실제 클라우드 추론은 실행하지 않았습니다. 실제 유료 호출의 성공·응답 시간·한국어 정확도는 미검증입니다.

## 수집·화면·자동 검사

국민은행·농협 전체·농협정보시스템의 공개 목록과 상세 접근을 확인했습니다. 국민은행 페이징은 3페이지에서 서로 다른 30건을 확인했고 공개 PDF 다운로드에도 성공했습니다. 선택한 농협·농협정보시스템 공고는 공개 상세에서 외부 전자구매 시스템을 안내해 첨부는 원본 확인 상태로 표시했습니다. 전체 공고의 첨부 접근이나 실제 투찰 로그인을 검증한 것은 아닙니다.

자동 테스트 27개가 통과했습니다. HWP 확장 레코드·제어문자·압축 플래그, 파일 형식·XML 순서, 변경 파일 캐시, ZIP 경로 이탈·변경 첨부, 스캔·텍스트 혼합 PDF, 분야 필터·중복 사전 검사, 후반부 요구사항, JSON 오류, 비용 예약·재시도·로컬 전환, 허위 인용 제거, 은행 간 ID 충돌·상태 보존과 Streamlit 필터·상세 화면을 합성 fixture로 검증했습니다.

```bash
.venv/bin/python -m unittest discover -s tests
```

Streamlit AppTest와 실제 데스크톱 브라우저에서 페이지를 확인했습니다. 기존 서버가 이전 모듈을 유지해 발생한 가져오기 오류는 해당 앱을 재시작해 해결했습니다. Python AST 검사와 `git diff --check`를 수행했고 마크다운 H1·헤더·코드 블록·후행 공백을 자체 확인했습니다. Ruff와 markdownlint는 설치되지 않아 실행하지 않았습니다. R2 원격 업로드·복원과 모바일 화면은 검증하지 않았습니다.

## 로컬 검증 자료

검증 JSON과 화면은 Git 제외 대상인 `data/`에 보관합니다. `model_benchmark.json`, `document_validation.json`, `backfill_validation.json`, `performance_validation.json`, `source_validation.json`, `actual_analysis_validation.json`, `page_validation.jpg`로 구분합니다. 소스 접근 자료는 확인 당시의 일부 공고에 대한 결과이며 최신 공개 접근 상태를 보장하지 않습니다.
