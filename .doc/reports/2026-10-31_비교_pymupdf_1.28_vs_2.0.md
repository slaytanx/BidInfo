# PyMuPDF 1.28.2 대 2.0 PDF 변환 비교

최신 업데이트: 2026-10-31

`pymupdf` 2.x 업그레이드([결정 기록](../decisions/2026-10-31_pymupdf_2x_업그레이드.md))를 앞두고 실제 공고 첨부 PDF로 두 버전의 출력을 비교한 기록입니다. 원문에 개인정보가 있을 수 있어 수치와 구조만 남기고 원문은 인용하지 않습니다.

## 조건

- 표본: 첨부 샘플(2026-10-21 수집) 중 하나·국민·농협 PDF 16건, 총 108쪽. 신한 표본에는 PDF가 없습니다.
- 호출: `pymupdf4llm.to_markdown(path, page_chunks=True, ocr_language='kor+eng')`. `hwp_parser._pdf_segments()`와 같은 설정입니다.
- 환경: macOS, Python 3.14, Tesseract `kor+eng`. 두 버전을 별도 가상환경에서 같은 파일로 실행했습니다.
- 지표: 처리 시간, 추출 글자 수, Markdown 표 구분선 개수, `difflib` 문자 유사도.

## 판단

2.0은 표·목록 인식이 조금 나아졌고 속도도 약간 빨라졌습니다. 나빠진 점은 빈칸이 많은 서명란 줄이 합쳐지는 정도라 LLM 분석에는 영향이 작습니다. 업그레이드를 유지합니다.

## 한계

- PDF만 비교했습니다. HWP·HWPX·XLSX·DOCX 경로는 이번 업그레이드와 관계없습니다.
- 표본이 16건이라 드문 레이아웃의 차이는 다루지 못했을 수 있습니다.
- 표 개수는 구분선 줄 기준이라 표 품질까지 보여주지는 않습니다. 품질은 차이 난 쪽만 구조를 확인했습니다.
