# 향후 개선 아이디어 및 기능 확장 로드맵

최신 업데이트: 2026-11-06

본 문서는 입찰정보 수집·분석 시스템의 지속적인 고도화를 위해 검토된 핵심 확장 아이디어(알림 및 운영 자동화, 수집 대상 확대, AI 분석 품질 평가 도구 등)를 체계적으로 정리하여 보존합니다.

## 1. 알림 및 운영 자동화 (Alerts & Automation)

### 1.1. 고적합 입찰 공고 Webhook 알림 연동
* **목적**: 사용자가 웹 대시보드에 상시 접속해 있지 않아도 자사 비즈니스에 부합하는 핵심 공고를 실시간으로 인지.
* **연동 대상**: Slack (Incoming Webhook), Microsoft Teams, Discord, 카카오톡 나에게 보내기 API 등.
* **동작 명세**:
  * 수집 및 AI 분석 완료 시, `fit_score >= 80`(또는 관리자가 설정한 임계값) 이상인 신규 공고 필터링.
  * 메시지 템플릿:
    ```markdown
    🚨 [고적합 입찰 공고 알림] (적합도: 90점)
    • 사업명: [KB국민은행] 지능형 위협 대응 보안 고도화 구매 입찰공고
    • 발주처: KB국민은행 | 마감일시: 2026-11-20 17:00 (D-14)
    • 핵심 요약: 침입차단시스템(방화벽) 및 침입탐지시스템(IDS) 노후 장비 교체 및 이중화 구축
    • 바로가기: [원본 공고 링크]
    ```
* **구현 방안**:
  * `settings` 테이블에 `webhook_url`, `webhook_min_score`, `webhook_enabled` 설정 추가.
  * `pipeline.py`의 수집 배치 종료 지점에 `notify_high_fit_bids()` 훅 연동.

### 1.2. 일일 백그라운드 정기 자동 수집 (Daily Scheduler)
* **목적**: 매일 업무 시작 전(예: 평일 08:30) 자동으로 최신 입찰 공고를 크롤링하고 분석해 두어 즉시 업무에 활용.
* **구현 방안**:
  * macOS `launchd` 데몬 플리스트(`com.bidinfo.daily.plist`) 또는 리눅스/클라우드 `cron` 스크립트 작성.
  * 기존 CLI 인터페이스(`main.py --site "전체" --start ...`)를 활용하는 전용 배치 러너(`scripts/daily_batch.py`) 구성.
  * 크롤링 로그 및 결과 요약을 `data/logs/`에 자동 저장하고 에러 발생 시 알림 전송.

## 2. 수집 대상 금융사 커버리지 확장 (Target Coverage)

### 2.1. 우리금융그룹 / 우리에프아이에스(`woorifis.com`) 전용 스크래퍼
* **목적**: 5대 시중은행(KB국민, 신한, 하나, 농협, 우리) IT 계열사 수집 라인업 완성.
* **타깃 사이트**: 우리FIS 입찰공고 (`https://www.woorifis.com`)
* **요구 규격**:
  * 우리FIS 공지/입찰 게시판 HTML 페이징 구조 분석.
  * 보안 토큰 또는 세션 헤더 분석 및 `curl_cffi` 기반 핸들러 구현.
  * 첨부파일(제안요청서, 규격서) 자동 다운로드 및 파일명 정제 매핑.

### 2.2. 국책 금융기관 및 공공 조달 연계
* **IBK기업은행 (`ibk.co.kr`)**: 기업은행 전자구매/입찰 공고 게시판 스크래퍼.
* **KDB산업은행 (`kdb.co.kr`)**: 산업은행 IT 발주 공고 연동.
* **나라장터 (KONEPS)**: 조달청 공공데이터 API 또는 사전규격/입찰공고 연계를 통한 금융·공공 IT 용역 포괄 수집.

## 3. AI 분석 품질 검증 및 비교 분석 (Quality & Intelligence)

### 3.1. Ground Truth 기반 AI 추출 정확도 정량 평가 도구 (`eval`)
* **목적**: LLM 모델 교체(DeepSeek, Solar, Gemma 등)나 프롬프트 변경 시, 추출 신뢰성을 감(感)이 아닌 데이터 기반으로 검증.
* **기반 자산**: `tests/eval/truth/` 내 8개 금융사 실제 공고 정답 셋(Ground Truth).
* **평가 지표**:
  * **마감일시 / 제출방식 / 필수서류 / 자격요건 / 예산 / 기간** 항목별:
    * 일치도 / 재현율 (Recall): 정답 서류 중 LLM이 누락 없이 추출한 비율.
    * 정밀도 (Precision): LLM이 추출한 항목 중 실제 정답과 부합하는 비율.
    * 환각율 (Hallucination Rate): 원문에 없는 허위 사실 추출 비율.
    * 인용 근거 일치율 (Quote Grounding Accuracy): 인용된 위치와 실제 원문 일치 여부.
* **실행 형태**: `python -m eval --model deepseek/deepseek-v4-flash-0731` 형식의 벤치마크 리포트 출력.

### 3.2. 입찰 공고 1:1 유사도 비교 뷰 (Side-by-Side Compare)
* **목적**: 유사 사업 간(예: 전년도 사업 vs 금년도 사업, 또는 타행 유사 프로젝트) 조건 대조를 통한 제안 전략 수립.
* **기능 명세**:
  * UI에서 2~3개 공고 다중 선택 시 '비교 뷰' 활성화.
  * 테이블 좌우 대조: 사업 예산, 수행 기간, 핵심 참가 자격, 평가 배점(기술:가격), 필수 제출 서류 차이점을 나란히 시각화.
